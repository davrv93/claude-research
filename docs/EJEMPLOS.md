# Ejemplos para alumnos

Primero escribe `/research-academy` y elige la skill; luego el pedido. Donde dice "este archivo", se suelta en el panel, no en el chat.

## Investigar y explicar
1. `investiga: cuál es el sueldo mínimo vigente en Perú`
2. `investiga: precio del kilo de pollo en Lima esta semana`
3. `¿cuáles son las 3 plataformas de ecommerce más usadas en Perú?`
4. `explícame qué es el IGV con un ejemplo de bodega`
5. `¿qué es la matriz FODA y cuándo conviene usarla?`
6. `explícame en 100 palabras cómo funciona un préstamo con cuota fija`

## Archivos (suelta el archivo en el panel)
7. `quiero un ppt resumen de este pdf`
8. `resume este pdf en 5 puntos`
9. `corrige las fórmulas de este excel`
10. `limpia los datos de este excel`
11. `hazme un gráfico de ventas por vendedor de este excel`
12. `compara este excel con el del mes pasado`
13. `arma mensajes de WhatsApp para cada cliente de esta lista`
14. `añade a este word una sección sobre el sueldo mínimo vigente con fuentes`
15. `añade las referencias en APA a este word`
16. `convierte este pdf a word`
17. `hazme fichas de estudio y un examen de práctica de este pdf`
18. `revisa si este trabajo tiene frases copiadas de internet`
19. `pasa esta foto de la boleta a excel`
20. `escribe un texto para Instagram con esta foto de mi producto`
21. `transcribe este audio de la clase y hazme un resumen`

## Crear desde cero
22. `hazme una plantilla de excel de inventario con stock mínimo y aviso de reposición`
23. `hazme una plantilla de excel de caja diaria con saldo acumulado`
24. `redacta una carta de solicitud de crédito para mi bodega`
25. `redacta un informe de ventas del mes con [datos entre corchetes para completar]`

## Código
26. `escribe en javascript una función que valide un DNI peruano`
27. `corrige este error de python: ZeroDivisionError en promedio([])`
28. `explícame qué hace este código` (pegar el código en el panel)
29. `escribe tests para esta función`
30. `convierte este código de python a javascript`

## 3D
31. `render3d una silla de madera con respaldo curvo`
32. `render3d un dron de cuatro hélices estilo low poly`
33. `render3d` y soltar una foto del producto en el panel

## Calculadoras y citas
34. `calcula un préstamo de 10 mil soles a 24 % en 12 meses`
35. `calcula el punto de equilibrio: fijos 3000, precio 10, costo variable 6`
36. `dame la cita APA de https://gob.pe/...`

## Cerebro y plan
37. `muéstrame mi mapa mental`
38. `¿qué tengo guardado sobre sueldo mínimo? mi frase es ...` (solo el alumno)
39. `dame el código para compartir mi cerebro con mi asesor`
40. `/plan-trabajo quiero abrir una segunda bodega en 3 meses con 15 mil soles, asume lo que falte`
41. `/plan-trabajo terminé la fase 1, la fase 2 está trabada por el proveedor; actualiza el estado`

## Configuración y medición
42. `configurar`
43. `dime cuántos tokens usamos en esta sesión`

Archivos de prueba del taller: `prueba-informe-bodegas.pdf` (22 páginas) y `prueba-ventas-bodega.xlsx` (fórmulas con rango corto, una celda con error, datos sucios). Se generan con los scripts del piloto; pedirlos al instructor.
